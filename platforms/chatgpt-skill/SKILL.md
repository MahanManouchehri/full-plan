# Full Plan

پیش از طراحی یا پیاده‌سازی هر فیچر APIمحور، «طرح API و سناریوها» را به فارسی طبیعی و فنی آماده کن. هدف این است که کاربر پیش از تغییر کد بداند هر endpoint چه ورودی می‌گیرد، چه رفتاری دارد، چه پاسخی برمی‌گرداند و در کدام گام سناریو استفاده می‌شود.

این Skill برای درخواست‌های مرتبط به‌صورت خودکار قابل استفاده است. اگر کاربر `/full-plan` را فرستاد، آن را درخواست صریح اجرای کامل این روند بدان.

## بررسی پیش از طرح

اگر به پروژه، کد، مستندات یا فایل‌های مرتبط دسترسی داری، فقط منابع لازم را بررسی کن: routeها، controller یا service، validation، serializer یا resource، مجوزها، پاسخ‌ها و مستندات API. بین endpointهای «موجود»، «پیشنهادی» و «نیازمند تصمیم» تمایز روشن بگذار. مسیر، فیلد، status code یا پاسخ را بدون شواهد قطعی اعلام نکن.

## خروجی الزامی

خروجی را با عنوان «طرح API و سناریوها» ارائه کن. برای هر endpoint، مستقل و شماره‌گذاری‌شده، این چهار بخش را بنویس:

1. **نام endpoint:** نام خوانا، method، مسیر، وضعیت موجود یا پیشنهادی، و نقش یا مجوز لازم در صورت وجود.
2. **پارامترهای ورودی:** path، query، body و header را با نام، نوع، اجباری‌بودن، نمونه، اعتبارسنجی و کاربرد نمایش بده. اگر ورودی ندارد، صریحاً بگو.
3. **رفتار endpoint:** اعتبارسنجی، بررسی مجوز، عملیات اصلی و نتیجهٔ قابل مشاهده را کوتاه توضیح بده.
4. **فرمت دقیق خروجی:** پاسخ موفق را با JSON و status code نشان بده؛ تک‌تک فیلدها را توضیح بده؛ خطاهای قابل انتظار، علت و status code آن‌ها را نیز بنویس. پاسخ نامشخص را «نیازمند تصمیم» علامت بزن.

کلیدهای JSON، مسیرها و شناسه‌های قراردادی را دست‌نخورده نگه دار. متن توضیحی باید فارسی رسمی، مستقیم و قابل مرور سریع باشد.

## سناریوهای ترتیبی

پس از endpointها، سناریوها را به ترتیب واقعی اجرا بنویس. هر سناریو باید نقش یا هدف مشخصی داشته باشد. برای هر گام بگو بازیگر چه می‌کند و چرا، از کدام endpoint استفاده می‌کند، ورودی یا خروجی مهم چیست، چه چیزی به گام بعدی منتقل می‌شود و نتیجهٔ قابل مشاهده چیست.

## شرط توقف

در پایان، endpointهای موجود، پیشنهادی و تصمیم‌های باز را جمع‌بندی کن و برای شروع پیاده‌سازی تأیید صریح کاربر را بخواه. تا دریافت تأیید، کدنویسی، تغییر قرارداد API، migration یا اقدام اجرایی را شروع نکن.
